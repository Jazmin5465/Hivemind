
## Operational datasets
- Keep network and operations JSON plus compact sensor frames as source-controlled data, generated by the ingestion script; this avoids shipping a large raw CSV while preserving every timestamp.
- Derive displayed state and event history from telemetry in a browser-safe data module; never import answer keys into application code.

## Operator decisions
- Keep deterministic event-time remediation and priority/history derivation in a browser-safe operations module, separate from raw telemetry ingestion; this makes economic rules independently testable.
- Persist no-account decisions in browser storage with plans derived from the operations module; this enables submission without exposing other operators' Cloud records.
- Share browser-saved decisions through a root provider across public dashboard and timeline pages; this keeps both views consistent without sign-in.
- Relationship edges connect explicit event IDs (incident to recovery or item to decision), never adjacent timestamps; chronological proximity alone is not evidence of causality.
- Prebundle dialog, radio-group, and Cloud sign-in dependencies at Vite startup; late dependency discovery can invalidate React's module graph while a popup is mounting.
